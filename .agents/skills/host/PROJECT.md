# Readiness lifecycle host
Lifecycle Host: readiness-run-store. Artifact Map: request_id binds normalized input,
authorized source evidence, authenticated answers, both full impact reports and assessment.
Persist artifacts through the backend run store; do not post comments or messages externally.
Human Gates: required by default. Only current backend project policy may enable auto.
The backend vetoes incomplete reports and blockers, and requires human selection for uncertainty.
Assess only. No implementation, merge, deployment, artifact initialization or external writes.
